# DootSport Pro

واجهة عربية مستقلة لمركز كرة القدم. رابط النشر المتوقع: https://7oda90.github.io/DootSport/

بدون API Token، تعرض الصفحة بيانات توضيحية وليست نتائج حقيقية. احصل على مفتاح من https://www.football-data.org/client/register. تغطية البطولات تختلف حسب الخطة: https://www.football-data.org/coverage

لا تضع مفتاح API داخل كود عام للإنتاج؛ الأفضل استخدام Backend أو Worker يخفي المفتاح. هذا المجلد لا يستبدل الصفحة الرئيسية ولا يعدّل ملفات الموقع الأصلي.
